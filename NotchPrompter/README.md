# NotchPrompter：刘海提词器

在 Claude 桌面客户端提问后，回复会从 MacBook 的刘海处展开，像提词器一样单行滚动播放，速度可调。

## 功能

- **自动播放**：Claude 开始输出正文时，刘海下方展开一条黑色区域，文字从右向左滚动。回复还在生成时，播到已有文字的末尾会停下等待。
- **调速**：菜单栏图标里可选慢（4 字/秒）、中（7 字/秒）、快（11 字/秒），也可以用滑块在 2–20 字/秒之间调节。设置会被记住。
- **调宽度**：菜单里可选窄（360 pt）、中（480 pt）、宽（640 pt），也可以用滑块在 280–1000 pt 之间调节。调整时刘海处会短暂显示黑条预览；正在播放时直接生效。宽度不会窄于刘海，也不会超出屏幕。设置会被记住。
- **跟随 Claude 所在桌面**：只在 Claude 所在的桌面上显示。切到其他桌面时提词器收起并暂停，刘海恢复原样；切回来后从暂停处继续。Claude 最小化或隐藏时，只要还在它原来的桌面，照常读取和显示。Claude 全屏时也能显示。"测试滚动"和调宽度时的预览不受这条限制。
- **进度提示**：文字下方有一条细进度条；刘海右侧显示按当前速度还要播多久（如"剩余 1:20"）。回复还在生成时显示"剩余 1:20+"，已追上 Claude 的输出时显示"等待中"，暂停时显示"已暂停"。
- **跳到最新**：积压太多时，把鼠标移到刘海区域，点左侧出现的"跳到最新"按钮（或菜单里的"跳到最新"），会跳过积压内容，直接播放最新的文字。
- **悬停暂停**：鼠标移到刘海区域时暂停滚动。
- **展开回看**：点击后展开成多行，可以滚动查看全文；鼠标移开后收起。
- **自动收起**：播放完毕 2.5 秒后自动收起。
- **只播正文**：跳过思考过程、读屏提示、按钮，以及卡片加载时的占位文字。
- **测试滚动**：菜单里的"测试滚动"不需要 Claude，用来检查显示效果和速度。

## 环境要求

- macOS 14 或更高版本，带刘海的 MacBook 效果最好（没有刘海的屏幕会显示在菜单栏下方正中）
- Xcode 或 Command Line Tools（需要 `swift` 命令）
- Claude 桌面客户端

## 运行

```bash
cd NotchPrompter
swift run -c release
```

在终端里运行时，程序沿用终端的辅助功能权限。之前运行 `ax-probe` 时已经给终端授过权，所以不需要重新设置。

启动后菜单栏会出现一个对话气泡图标，终端窗口需要保持打开。点开菜单，第一行显示连接状态：

| 状态 | 含义 |
|---|---|
| 正在监听 Claude | 一切正常，去 Claude 里提问即可 |
| 已连接 Claude，打开一个聊天即可 | Claude 当前不在聊天页面，或是还没有消息的新会话 |
| Claude 已打开，等待聊天窗口 | Claude 的窗口被关闭或最小化了 |
| 没有找到 Claude 客户端 | Claude 没有运行 |
| 需要辅助功能权限 | 到 系统设置 → 隐私与安全性 → 辅助功能 里勾选终端，然后重新运行 |

## 已知限制

- 依赖 Claude 客户端的界面结构。Claude 更新后如果不再播放，可以用 `spike/ax-probe` 的 `locate` 命令重新查看结构，再修改 `Sources/NotchPrompter/ClaudeUI.swift`。
- 只播放 Claude 窗口里当前打开的会话。
- 回复生成速度通常远快于阅读速度，长回复会在回复结束后继续播放一段时间。
- 目前需要从终端启动。打包成可以双击打开的 `.app` 留到后续再做。

## 代码结构

| 文件 | 作用 |
|---|---|
| `AX.swift` | 辅助功能 API 的基础封装 |
| `ClaudeUI.swift` | Claude 页面结构：找到消息列表、最后一条回复，并提取正文 |
| `ClaudeReader.swift` | 后台线程轮询（每 250ms），把变化转成"开始 / 新增文字 / 结束"事件 |
| `TickerView.swift` | 单行滚动视图，按字/秒控制速度 |
| `NotchPanel.swift` | 覆盖刘海的无边框面板和黑色背景 |
| `PrompterController.swift` | 面板的显示、隐藏、悬停暂停和展开 |
| `AppDelegate.swift` | 菜单栏图标和菜单 |
